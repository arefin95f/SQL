# SQL JOINs

## What I Built
Combined sales, products, employees, and regions tables using different types of JOINs. Created analytical queries with aggregations across multiple tables.

## What I Learned Today
- INNER JOIN (matching records only)
- LEFT JOIN (all from first table)
- RIGHT JOIN (all from second table)
- Simulating FULL OUTER JOIN with UNION
- Self JOIN (table joined to itself)
- Multi-table JOINs (3+ tables)
- JOINs with GROUP BY and aggregations
- Finding unmatched records (NULL checks)

## Key Insights
- INNER JOIN replaces VLOOKUP for combining tables
- LEFT JOIN finds products never sold
- RIGHT JOIN finds regions with no employees
- Self JOIN compares rows within same table
