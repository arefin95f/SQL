# Subqueries & CTEs

## What I Built
Wrote complex analytical queries using subqueries in WHERE, SELECT, and FROM clauses. Refactored them into readable CTEs and learned window functions for running totals.

## What I Learned Today
- Subqueries in WHERE (filtering with dynamic values)
- Subqueries in SELECT (adding calculated columns)
- Subqueries in FROM (querying query results)
- CTEs (Common Table Expressions) with WITH clause
- Multiple CTEs in one query
- WHERE vs HAVING
- Window functions (SUM OVER for running totals)

## Subquery vs CTE
- Subquery: Query inside another query, good for simple cases
- CTE: Named temporary result, better for complex logic and readability
